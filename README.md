# Juan1

Este projeto é um site com livros sobre computação gráfica e programação. A ideia foi desenvolver um sistema simples que pudesse avaliar minhas habilidades.

## Livros

- Computação gráfica e boas práticas;
- Algoritmos e estruturas de dados.

## Como abrir

Abra o arquivo `index.html` no navegador para ver o site.

## Arquivos principais

- `index.html`: página inicial com os livros.
- `src/pages/`: páginas com mais informações sobre cada livro.
- `src/css/style.css`: aparência do site.
- `src/js/main.js`: código da página de download.
- `src/assets/`: capas e arquivos PDF.
